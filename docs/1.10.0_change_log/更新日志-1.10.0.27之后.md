## 五、口径与已知偏差

1. **上游带入的提交不计入**：三条分支都同步了上游 1.21.1 主线（onixary / xu233333 / niebh / MM-Rabbit 共 199 条），这些提交属于上游作者，本文档只汇总 A Cat 名下的提交；「合并上游」类快照提交本身也按内部项列出、不算功能变更。
2. **两种提交混在 A Cat 名下**：本项目的人工提交与 AI 协作提交共用同一 git 身份，无法按 author 区分；是否写入正式发布说明请人工复核。
3. **26.1 缺两笔 1.21.11 提交**：`ebb487ba`（版本号）与 `afc836de`（专用服务器蛛网方块）；蛛网问题在 26.1 早已由等价实现解决（`ModBlocks.register()` + `Origins` 显式调用），功能上无缺口。
4. **条目粒度**：标题笼统的提交仅按改动文件归类，未逐条读 diff；需要精确结论时以对应 commit 为准。
5. **纯注释与构建噪音**：`39fe3d63`（167 文件注释整理）等条目属内部维护，玩家不可见。
